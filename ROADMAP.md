# 🗺️ Roadmap — Agyl Agro

Este documento registra el desarrollo de las herramientas que forman parte de Agyl Agro.

Agyl Agro sigue un principio fundamental:

> Una herramienta, un problema, una solución útil.

El desarrollo se concentra en una herramienta a la vez. Una nueva herramienta podrá iniciar cuando exista una necesidad concreta que justifique su desarrollo.

---

# 🌱 Herramienta 01 — Fertilización

**Estado:** 🟡 En desarrollo

## Problema

Facilitar a productores agrícolas la determinación de la cantidad de fertilizante que necesitan aplicar según las características de su cultivo y la etapa correspondiente del proceso productivo.

La herramienta deberá transformar criterios agronómicos en una experiencia sencilla para el productor.

---

## Etapa 1 — Definición funcional

- [ ] Definir exactamente qué datos deberá ingresar el productor.
- [ ] Definir cultivos iniciales.
- [ ] Definir etapas o ciclos de fertilización.
- [ ] Definir fertilizantes/productos iniciales.
- [ ] Definir unidades de medida.
- [ ] Definir qué resultado recibirá el productor.
- [ ] Definir qué información adicional acompañará la recomendación.

**Participación clave:** validación agronómica.

---

## Etapa 2 — Motor de cálculo

- [ ] Documentar la lógica agronómica.
- [ ] Definir variables y fórmulas.
- [ ] Crear tablas técnicas necesarias.
- [ ] Definir reglas y restricciones.
- [ ] Crear casos de prueba.
- [ ] Validar resultados con un profesional agrónomo.

El motor de cálculo deberá estar separado de la interfaz para permitir su reutilización y mantenimiento.

---

## Etapa 3 — Prototipo

- [ ] Diseñar flujo de usuario.
- [ ] Diseñar interfaz.
- [ ] Implementar formulario de entrada.
- [ ] Implementar motor de cálculo.
- [ ] Mostrar recomendación.
- [ ] Crear una primera experiencia funcional de principio a fin.

**Meta:** poder realizar un cálculo real desde un navegador.

---

## Etapa 4 — Validación

- [ ] Pruebas técnicas.
- [ ] Revisión agronómica.
- [ ] Pruebas con casos reales.
- [ ] Pruebas con productores.
- [ ] Identificar errores y dificultades de uso.
- [ ] Ajustar cálculos e interfaz.

**Meta:** comprobar que la herramienta sea técnicamente válida y sencilla de utilizar.

---

## Etapa 5 — Producto comercial

- [ ] Definir mecanismo de acceso.
- [ ] Definir gestión de usuarios si resulta necesaria.
- [ ] Preparar infraestructura de producción.
- [ ] Implementar seguridad básica.
- [ ] Preparar documentación de uso.
- [ ] Preparar soporte.
- [ ] Definir proceso de entrega/activación.
- [ ] Realizar lanzamiento inicial.

**Meta:** primera venta de una herramienta Agyl Agro.

---

# 🔮 Próximas herramientas

No se desarrollarán nuevas herramientas únicamente para ampliar el catálogo.

Las futuras herramientas de Agyl Agro surgirán de problemas concretos detectados en el sector agrícola.

Cuando una nueva necesidad sea seleccionada para desarrollo, se incorporará a este roadmap sin eliminar las herramientas anteriores.

---

## Regla de desarrollo

Antes de incorporar una funcionalidad o nueva herramienta se deberá responder:

> ¿Qué problema concreto resuelve?

Si no existe una respuesta clara, no se prioriza su desarrollo.
